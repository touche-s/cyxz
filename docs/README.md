## 当前项目状态（2026-08-19）

### 模块

- C 端业务服务：**9 个**（含网关 gateway，纯业务 8 个）
- B 端治理服务：**3 个**（governance / audit / analytics）
- 共享模块：**2 个**（common / security）
- *-api 模块：**8 个**

### B 端能力

已实现 **11 个**管理入口：圈子管理、板块模板、内容审核、用户管理、帖子管理、举报管理、审计日志、数据看板、建圈申请、入圈申请、角色权限

### 权限体系

- RBAC：6 角色 / 35 权限码
- 圈子资源权限：`CirclePermissionEvaluator` 圈子粒度授权
