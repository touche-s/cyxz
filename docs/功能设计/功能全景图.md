> 最后更新：2026-08-17
>

## 总览

- **C 端**：18 条路由（其中 13 条需登录），覆盖内容、社交、圈子、消息、搜索、创作中心
- **B 端**：平台管理后台 11 个 tab + 圈主工作台（圈子粒度管理）
- **后端**：23 个 Controller / 约 150 个接口，其中 internal 接口 12 个（服务间 Feign 调用，不经网关暴露）

```
次元小站
├─ C 端（社区本体）
│   ├─ 认证与账号：登录注册 / 验证码 / 改密 / 个人资料
│   ├─ 内容：发帖(AI初审) / 帖子文章双形态 / 点赞收藏 / 评论回复
│   ├─ 社交：关注粉丝 / 私信(互关前置)
│   ├─ 圈子：浏览 / 加入退出 / 圈内板块 / 建圈入圈申请
│   ├─ 消息：通知中心 / 已读管理 / 未读数
│   ├─ 搜索：ES 全文检索
│   └─ 创作中心：数据看板 / 内容管理 / 收到的赞
├─ B 端（平台管理后台 /admin，11 tab）
│   ├─ 内容治理：内容审核 / 帖子管理 / 举报管理
│   ├─ 用户治理：用户管理 / 角色权限(RBAC)
│   ├─ 圈子治理：圈子管理 / 板块模板 / 建圈申请 / 入圈申请
│   └─ 数据与合规：数据看板 / 审计日志
└─ B 端下沉（圈主工作台 /circle/:id/admin）
    ├─ 圈内审核：成员发帖审核
    ├─ 成员管理：晋升降级 / 移除成员
    └─ 圈内板块：自定义板块编排
```

## 1. 认证与账号域

| 功能 | 服务 | 前端入口 | 关键接口 |
|---|---|---|---|
| 登录（防时间侧信道） | auth | 登录弹窗 | `POST /auth/login` |
| 注册（验证码校验） | auth | 注册页 | `POST /auth/register` · `GET /auth/captcha` |
| 登出（token 拉黑） | auth | 顶栏 | `POST /auth/logout` |
| 修改密码 | auth | 用户中心·账号安全 | `PUT /auth/password` |
| Token 无感续期 | auth + frontend | 全局请求层 | `POST /auth/refresh` |
| 个人资料查看/编辑 | user | 用户中心 · 个人空间 | `GET /user/profile/me` · `PUT /user/profile` · `GET /user/{id}` |
| 头像上传与历史 | upload | 用户中心 | `POST /upload/avatar` · `GET /upload/avatar-history` |

## 9. 圈主工作台（B 端能力下沉，`/circle/:id/admin`）

| 功能 | 服务 | 关键接口 |
|---|---|---|
| 圈内发帖审核 | post | `GET /post/circle/{circleId}/admin/review/pending` · `PUT .../approve\|reject` |
| 圈内帖子管理 | post | `DELETE /post/circle/{circleId}/admin/{postId}` |
| 成员管理（晋升/降级/移除） | circle | `PUT /circle/{id}/members/{uid}/promote\|demote` · `DELETE /circle/{id}/members/{uid}` |
| 成员列表 | circle | `GET /circle/{id}/members` |
| 圈内板块编排 | circle | `PUT /circle/{id}/sections` |
| 入圈审批（圈主侧） | circle | 同 `/admin/circle-join-application`（权限校验区分圈主/平台） |

> 圈主是"个人用户行使组织权力"的角色，权限走圈子级 RBAC（`CirclePermissionEvaluator`），是 B 端权限模型下沉到 C 端场景的实践。

## 服务间 internal 接口（不暴露给前端）

| 接口 | 提供方 | 消费方 | 用途 |
|---|---|---|---|
| `GET /circle/internal/{id}/publishable` | circle | post | 发帖前校验圈子状态 |
| `GET /circle/internal/batch-names` | circle | post 等 | 列表流圈子名聚合 |
| `GET /circle/internal/section/batch-names` | circle | post | 板块名聚合 |
| `POST /user/internal/profile/batch` | user | post/comment 等 | 作者信息聚合 |
| `GET /user/internal/following-ids` | user | post | 关注动态流 |
| `GET /post/internal/{id}/info` · `/batch-info` | post | comment/governance | 帖子信息（治理联动） |
| `GET /post/internal/batch-circle-post-count` | post | circle | 圈子帖子数（事件驱动，此为兜底查询） |
| `DELETE /comment/internal/post/{postId}` | comment | governance | 下架联动删评论 |
| `GET /comment/internal/today` | comment | post | 创作中心今日评论数 |

> internal 接口仅服务间调用，网关不暴露；权限隔离依赖网络层（见 [权限设计.md](./权限设计.md) 的已知边界）。
